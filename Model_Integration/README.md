# Framework_Integration

This directory contains the intermediate data files exchanged between the three models of the Tri-Model Smart Justice Framework (TMSJ).

These files enable the sequential integration of the framework components and serve as inputs and outputs between the models.

## Files Description

### Model_A_to_Model_B_Clean_Inputs_Link.txt

Contains the access link to the cleaned and structured legal entities extracted by Model A (Reader/Extractor). These outputs are used as inputs for Model B scenario generation.

### Model_A_to_Model_B_Prompts_Link.txt

Contains the access link to the prompt dataset constructed from Model A outputs and used for training and evaluating Model B.

### Model_B_to_Model_C_Synthetic_Cases.jsonl

Contains the validated synthetic legal scenarios generated by Model B and used as input data for Model C judicial outcome prediction.

## Framework Data Flow

Model A (Legal Entity Extraction)
↓
Clean Inputs & Prompts
↓
Model B (Legal Scenario Generation)
↓
Synthetic Legal Scenarios
↓
Model C (Judicial Outcome Prediction)

These files are provided to support reproducibility and demonstrate the end-to-end integration process of the TMSJ framework.
